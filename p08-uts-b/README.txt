UTS PBO 2 Paket B - Daftar Belanja (gambaran, bukan jawaban resmi)

Cara membuka di NetBeans:
1. File > Open Project > pilih folder p08-uts-b (proyek Maven).
2. NetBeans akan mengunduh FlatLaf 3.5.4 otomatis (butuh internet sekali).
   Tanpa internet: pastikan FlatLaf sudah ada di ~/.m2 dari tugas sebelumnya.
3. Buka FormDaftarBelanja.java, tab Design untuk melihat/mengubah tampilan.
4. Run File (Shift+F6) pada FormDaftarBelanja.java.

Struktur: Kategori (enum), Barang (data + subtotal),
BarangTableModel (model tabel + total/diskon/bayar), FormDaftarBelanja (JFrame Form).
